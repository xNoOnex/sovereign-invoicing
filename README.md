# Sovereign Invoicing & Deployment Estimator

An offline-first, client-side utility suite for calculating software deployment scopes and generating binding fleet service agreements, bills of lading, and deployment invoices. 

Built specifically for zero-dependency execution across Android (Termux/Mobile Browsers) and standard desktop environments with zero recurring SaaS overhead.

## 🛠️ Modules Included
* **`estimator.html`:** Live modular breakdown for independent logistics, moving, and fleet operators. Computes flat-rate deployment fees and mandatory 50% mobilization deposits.
* **`contract-builder.html`:** Dynamic contract generation with customizable scopes, invoice numbering, and date tagging. Integrated `localStorage` draft auto-save.

## 🔒 Privacy & Architecture Ethos
1. **Zero External Dependencies:** Runs completely locally without third-party CDNs.
2. **Client-Side Security:** Data never leaves the client device unless exported manually.
3. **No Vendor Lock-In:** Generates standard PDF-compatible documents natively.
